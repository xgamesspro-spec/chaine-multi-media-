# Vérif' Monde : chaîne YouTube d'information

Chaîne qui compare la façon dont l'actualité est racontée en France, dans les Outre-mer (Guyane, Guadeloupe…) et dans d'autres pays.
Elle confronte ces récits aux faits vérifiés et explique **le pourquoi des décisions** : en réaction à quoi, quels autres choix existaient, qui gagne et qui perd.

## Les flags

| Flag | Sens |
|---|---|
| 🟢 VÉRIFIÉ | Confirmé par des sources primaires (documents officiels, données, décisions de justice) |
| 🔴 FAUX | Contredit par des preuves claires |
| 🟠 TROMPEUR | Vrai en partie, mais sorti de son contexte ou chiffre mal présenté |
| 🟡 NON PROUVÉ | Ni confirmé ni démenti pour l'instant |
| 🔵 PEU COUVERT | Fait vérifié mais peu relayé par les grands médias (preuve de couverture à l'appui) |
| ⚪ OPINION | Point de vue, pas un fait |
| 🗣️ RAISON OFFICIELLE | Ce que les décideurs disent eux-mêmes |
| 🔍 ANALYSE | Raison probable selon des experts, présentée comme une analyse |
| ⚠️ | Chiffre ou fait à revérifier avant le tournage |

## Règles éditoriales

- Toutes les sources sont dans la description de chaque vidéo.
- Les erreurs sont corrigées publiquement, avec un commentaire épinglé et le flag mis à jour.
- Les faits sont toujours séparés des opinions.
- On ne dit jamais « étouffé » ou « censuré » sans preuve d'une intervention. Sinon, on utilise 🔵 PEU COUVERT.
